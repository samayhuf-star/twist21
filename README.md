# Twist 21

Blackjack with action cards. Expo app wrapping a bundled game. Everything is free to play; optional consumable chip packs (`twist21_chips_*`) are sold through RevenueCat. Checks: `npm test` (rules, save and shop) and `npm run typecheck`.
See `LAUNCH_GUIDE.md` for the build and store steps and `store/listing.md` for the listing copy.

```bash
npm install
npm run build:html   # after editing game/index.html
npm start
```
