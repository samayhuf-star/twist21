# Twist 21

Blackjack with action cards. Expo app wrapping a single-page game, with a Chips Pass subscription and chip packs through StoreKit 2 (expo-iap), checked on device.
See `LAUNCH_GUIDE.md` for the build and store steps and `store/listing.md` for the listing copy.

```bash
npm install
npm run build:html   # after editing game/index.html
npm start
```
